# Kora — нативная сборка (HTML / CSS / JS)

Главная страница темплейта Kora, воспроизведённая в чистом коде без Framer.
Все скролл-механики оригинала реализованы на GSAP ScrollTrigger + Lenis.

## Запуск

Откройте `index.html` в браузере или поднимите сервер:

```bash
npx serve .        # или python3 -m http.server
```

## Анимации (js/main.js)

0. **Прелоадер** — страница открывается с маленькой карточки по центру,
   она разворачивается в hero, после чего контент hero появляется каскадом.
99. **Круг перед футером** — зелёный круг растёт по скроллу, заливает
   экран и перекрашивает фон в зелёный, футер продолжается бесшовно.


1. **Пин-интро (3 фазы, ~320vh скролла)** — hero закреплён; при скролле
   контент hero уезжает вверх и растворяется → появляется манифест
   «The strategies that built your company won't scale it.» с **пословной
   заливкой** (каждое слово 35% → 100% непрозрачности по мере скролла).
2. **Comparison (пин ~280vh)** — заголовок слева закреплён; справа карточка
   After (тёмная) **вытирает** карточку Before снизу вверх через clip-path,
   строки появляются со стаггером.
3. **Стек сервисов** — 5 sticky-карточек наезжают друг на друга,
   предыдущая слегка сжимается (scale 0.96).
4. **График ARR** — столбцы растут (scaleY 0→1) при входе в вьюпорт.
5. **Счётчики** — 47%, 2.4x и т.д. набегают через gsap snap.
6. Появления (fade-up) всех блоков, дрейфующие blur-пятна на hero,
   зерно поверх всей страницы (SVG-noise), навбар становится светлым
   после первого экрана.
7. Аккордеоны: фазы процесса, отзывы, FAQ (+ табы), чипы формы,
   копирование email по клику.

`prefers-reduced-motion` отключает анимации.

## Важно про изображения

Изображения подключены с CDN темплейта (`framerusercontent.com/...`).
Перед публикацией скачайте их локально и/или замените своими:
`grep -o 'https://framerusercontent[^"]*' index.html | sort -u`

## Токены (css/style.css → :root)

| Токен     | Значение  | Использование              |
|-----------|-----------|----------------------------|
| `--green` | `#5dc39b` | hero, секция Team, акценты |
| `--cream` | `#fffffa` | светлый текст/кнопки       |
| `--paper` | `#fcfcfa` | фон страницы               |
| `--beige` | `#f5f5e9` | карточки                   |
| `--dark`  | `#242424` | тёмные карточки/кнопки     |

Шрифт: Manrope (variable, локально в `assets/fonts/`).
Контейнер 1600px, радиусы 16/28px — как в оригинале.

## Примечания

- Тексты фич для планов Growth Partnership и Custom в демо скрыты
  за интерактивом — вписаны консистентные заглушки, замените своими.
- Видео-блок «How we work» — постер с кнопкой (ролика в демо нет).
